Clean Mode

Locks the keyboard and trackpad so you can wipe your Mac without typing, clicking or triggering shortcuts. Every screen shows a countdown while it is on.
Lock for2 minutes
Start Clean Mode
It unlocks on its own when the time is up. To unlock sooner, hold the Escape key for 3 seconds.

Permissions

Accessibility access granted
MacClean can block every key, including system shortcuts like ⌘ Tab and ⌘ Space, the volume and brightness keys and the Globe key.

Menu bar

Show MacClean in the menu bar
Start Clean Mode from the keyboard icon in the menu bar. While the icon is shown, MacClean keeps running after you close this window.

Tips

  • Switch the Mac off or use Clean Mode; never spray liquid on it. Use a soft, lint-free cloth, barely damp with water.
  • The power button (Touch ID) is handled by macOS before MacClean sees it, so avoid pressing it.
  • Clean Mode blocks input from every keyboard, trackpad and mouse, including Bluetooth ones.
